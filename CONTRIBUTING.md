# Contributing

Thanks for your interest. These guidelines apply across Quattrobit's open-source repos.

- Fork → branch → PR. Keep PRs focused and small.
- **Never commit secrets, tokens, or `.env` files.**
- Respect the open/closed boundary: open repos must not import from closed ones — shared
  interfaces live in a public `*-proto` / contracts repo.
- Run the repo's lint/tests before opening a PR.
- By contributing, you agree your work is licensed under that repo's LICENSE.
